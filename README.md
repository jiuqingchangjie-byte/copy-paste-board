# ClipboardBoard · 剪贴板

**中文** | [English](README.en.md)

一个原生 macOS 菜单栏剪贴板历史工具。按 **⌥ Option + V** 找回最近复制的文字、图片和文件，使用方向键选择，再按回车粘贴到原应用。

采用类似 Windows 剪贴板历史的紧凑卡片列表，支持浅色与深色外观。使用 Swift / AppKit 开发，无第三方包依赖，无账号和网络服务。当前版本 **1.5.0**，应用界面目前为中文。

## 直接下载安装

[下载 v1.5.0 应用包（Apple Silicon / M 系列 Mac）](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.5.0/ClipboardBoard-v1.5.0-macos-arm64.zip)

解压后将 `ClipboardBoard.app` 放入个人主目录下的 `Applications` 文件夹（`~/Applications`），再打开。不需要源码、Xcode、签名工具或 Apple 开发者会员。包内附有中英文安装说明。

应用使用固定自签名证书，**未经 Apple 公证**。首次打开若提示开发者无法验证，尝试打开后在「系统设置 → 隐私与安全性」选择「仍要打开」，再按提示授予辅助功能权限。[详细安装说明](docs/INSTALL_APP.md) · [Release 与校验文件](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/tag/v1.5.0)

## 功能

- **独立收藏库**：点击历史星标保存常用内容，收藏不占历史额度、没有 50 条上限；按文件夹整理，多选移动/取消收藏及一键清空。[产品方案与验收](docs/FAVORITES_AND_STORAGE.md)。
- **可配置存储**：通过“存储位置”迁移历史、收藏和设置，校验后切换、保留旧副本；已落盘内容可重启恢复。

- **JSON 格式化**：完整文本预览内一键格式化、查看原文；保持长数字精度，失败时显示原因，查看不改剪贴板和历史。[使用与验收](docs/JSON_PREVIEW.md)。
- **完整预览**：默认悬浮 1 秒查看全文，可滚动、选择片段复制；原图支持缩放和独立置顶拖动。延时与开关可在“完整预览选项”配置。[使用与验收](docs/PREVIEW.md)。
- **内容记录**：纯文本、PNG/TIFF 图片和 Finder 本地文件引用。
- **自定义快捷键**：在“自定义快捷键”中录制、保存或恢复默认；失败保留旧组合。[使用与验收](docs/CUSTOM_SHORTCUT.md)。
- **键盘操作**：全局快捷键呼出、方向键选择、回车粘贴、Esc 关闭；也支持双击使用。
- **搜索与去重**：按内容、文件路径或来源应用搜索；重复内容移到最前。
- **历史上限**：默认最近 10 条，可设置为 1–50 条，超出后淘汰最早记录。
- **文件保存**：默认保存于应用旁的 `ClipboardBoardData`，也可配置其他目录；历史和收藏独立持久化。
- **窗口与自启**：拖动标题区域保存窗口位置，支持登录自启和系统批准状态提示。
- **粘贴保护**：等待按键释放，尝试恢复原窗口和输入焦点；权限失效、应用切换或新的复制可取消待执行粘贴。
- **粘贴诊断**：查看权限、目标程序和最近执行结果，不读取输入框文本。

## 从源码安装

以下步骤只面向需要自行编译的开发者。普通用户下载上方应用包即可，无需生成证书或配置开发环境。

本机开发包构建后，可安装到固定位置：

```bash
./scripts/install-app.sh
open "$HOME/Applications/ClipboardBoard.app"
```

后续更新先退出应用，再运行安装脚本。脚本核对签名身份、保留目标数据目录，不重置系统权限。本机 1.2.4 → 1.2.5 及同身份重装已验证授权保留；首次使用仍需授权，用户撤销权限、系统重置或更换签名身份时可能需要重新允许。

### 1. 获取项目

```bash
git clone git@github.com:jiuqingchangjie-byte/copy-paste-board.git
cd copy-paste-board
```

SSH 克隆需要先在 GitHub 配置公钥，也可使用 HTTPS 地址：

```bash
git clone https://github.com/jiuqingchangjie-byte/copy-paste-board.git
cd copy-paste-board
```

### 2. 准备固定签名身份

首次在本机开发运行时：

```bash
# 只生成本地签名材料，不修改钥匙串。
./scripts/setup-local-signing.sh --prepare

# 导入登录钥匙串，并设置仅用于代码签名的用户信任。
./scripts/setup-local-signing.sh --install
```

安装步骤可能需要完成 macOS 钥匙串确认。签名材料位于 `.codesign/`，不纳入 Git；成功导入后会删除临时私钥包和包装密码文件。后续构建复用同一身份，不要删除或重新生成原证书。

### 3. 构建并打开

```bash
./scripts/build-app.sh
open dist/ClipboardBoard.app
```

如果已有有效代码签名证书，可以跳过第 2 步，改用以下构建命令：

```bash
CODE_SIGN_IDENTITY="你的代码签名证书名称或 SHA-1 指纹" ./scripts/build-app.sh
open dist/ClipboardBoard.app
```

缺少有效身份或意外更换固定身份时，构建脚本会停止并保留原应用包。已有应用可通过 `./scripts/run.sh` 启动，不会重新构建；更新后请先退出旧进程，再打开新版本。

当前应用包使用固定自签名证书，可在 GitHub 分发，不要求 Apple 开发者会员；首次打开仍受 macOS 安全策略管理。Developer ID 和公证是可选的后续分发方式，见 [安装与发布](docs/INSTALLATION.md)。

## 使用方法

先在目标应用的输入框中放置光标，再打开历史。

| 操作 | 快捷键或入口 |
| --- | --- |
| 打开 / 关闭历史 | **⌥V**，或点击菜单栏图标 |
| 选择记录 | **↑ / ↓** |
| 粘贴选中记录 | **Return**，或双击目标卡片 |
| 关闭面板 | **Esc**，或点击面板外 |
| 删除选中记录 | **⌘Delete** |
| 搜索 | 打开面板后直接输入关键词 |
| 完整内容预览 | 悬浮条目、右键菜单，或列表焦点下按空格；搜索空格仍输入文字 |
| 图片置顶 | 图片右键“查看原图” → “置顶固定”；拖动顶部移动 |
| 预览选项 | **… → 完整预览选项**，0.2–5 秒，可关闭悬浮 |
| 打开收藏库 | 顶部 **收藏**，或菜单 **打开收藏库** |
| 收藏 / 取消收藏 | 历史条目的星标或右键菜单 |
| 修改存储位置 | **… → 存储位置** |
| 修改历史上限 | **… → 历史记录上限** |
| 暂停 / 继续记录 | **…** 菜单，或右键菜单栏图标 |
| 登录自启 | **… → 登录时自动启动** |
| 清空历史 | 顶部 **全部清空**，或菜单中的清空入口 |

双击以实际点击的卡片为准，不要求先选中。拖动顶部标题、图标或空白区域可移动面板；清空和菜单按钮仍可正常点击。选取历史粘贴不会新增记录或改变复制顺序。

### 自动粘贴权限

通过面板的「去授权」进入 **系统设置 → 隐私与安全性 → 辅助功能**，允许当前 ClipboardBoard 应用。

应用优先通过辅助功能执行目标程序的粘贴菜单命令；系统按键发布权限是另一条可用路径，两项不要求同时开启。未授权时仍可记录和查看历史；回车或双击会提示未粘贴，不会自动变成只复制到剪贴板。

目标程序禁用粘贴时会报告不可用；菜单动作结果不确定时，不会自动补发第二次粘贴。可通过 **… → 粘贴诊断** 查看状态。原输入框恢复和内容接收仍取决于目标应用支持。

### 登录自启

使用打包后的 `.app`，放在固定且当前用户可写的位置后启用。仅运行 `swift run` 无法注册登录项。若显示「等待系统批准 · 尚未生效」，使用「去设置」完成批准，或关闭开关取消请求。

## 数据与隐私

```text
安装目录/
├── ClipboardBoard.app
└── ClipboardBoardData/
    ├── history.json
    ├── settings.json
    └── favorites.sqlite
```

- 历史与收藏保存完整文本、图片数据和文件 URL；文件本体不会被复制。收藏不参与普通历史淘汰。
- 自定义位置后，应用旁的 `ClipboardBoardConfig/storage-location.json` 记录数据目录；更新和移动应用时保留配置文件夹。位置不可用时提示重试，不自动回落到空目录。
- 选择云盘/网络目录时，外部软件可能同步这些文件；应用本身不主动联网。
- JSON 文件刷新后原子替换，收藏采用 SQLite 事务与完整同步；目录权限为 `0700`、数据文件权限为 `0600`，内容没有额外加密。未被采集或尚未写盘的最后一次复制不能保证在故障后恢复。
- 安装目录必须可写。移动应用时，将旁边的 `ClipboardBoardData` 一并移动；通过 **… → 打开数据目录** 定位。
- 旧版 Application Support 数据会尝试迁移。已有新数据（包括已清空的历史）优先，迁移失败会保留原文件并提示。
- 历史和设置带格式版本，兼容旧格式；高于 50 的旧上限和记录数自动收敛至 50。
- 读写异常可在 **… → 数据与恢复** 重试。损坏文件需用户选择保留后重建，原文件存于 `Recovery/`；恢复不会自动导回其中的历史，也不会撤销本次运行的删除和清空。更新版本格式不会被重建。
- 已识别的临时、隐藏、自动生成和密码管理器剪贴板标记会被过滤；没有这些标记的敏感内容仍可能被记录。
- 清空历史会保存空记录，但不更改系统当前剪贴板。删除和清空目前没有撤销功能。
- 暂停期间和启动前已有的内容不会补录；暂停状态不会跨重启保留。
- `.gitignore` 排除了历史目录、签名材料和构建产物。

## 已知限制

- 文本恢复为纯文本，不保留 HTML / RTF 格式。
- 单条记录上限为 **8 MiB**，超限跳过；正常历史按条数淘汰，没有总容量淘汰上限。
- 约每 **0.3 秒**检查一次剪贴板，极短时间内的多次复制可能只捕获最后一次。
- 默认快捷键为 **⌥V**，可在 **… → 自定义快捷键** 修改。冲突检查不能穷举其他软件的应用内快捷键或非排他监听；菜单栏入口始终可用。
- 文件引用在原文件移动或删除后可能失效。
- 历史保存在单个 JSON 文件，每次变化整体保存；大量图片可能增加存储、内存和启动开销。
- 当前没有跨设备同步或自动更新功能；图片置顶窗口仅限本次运行，长期保存请使用收藏库。

## 开发与验证

```bash
# 只编译，不安装签名证书、不启动应用。
swift build -c release

# Swift 模型、剪贴板、界面和粘贴状态机测试。
./scripts/test.sh

# 使用临时目录和模拟工具检查构建与启动流程。
python3 -m unittest discover -s Tests/Scripts -p 'test_*.py'
```

当前基线包含 **127 项 Swift 测试和 8 项构建与安装流程测试**。测试使用样例数据和独立剪贴板；粘贴环境采用模拟实现，不向用户应用发送按键。

可选生成 AppKit 浅色 / 深色布局预览：

```bash
CLIPBOARD_PREVIEW_DIR="$PWD/.build/previews" ./scripts/test.sh
```

已有签名应用和对应身份时，可验证更新后的身份一致性：

```bash
./scripts/verify-signing.sh
```

该脚本修改并重新签名临时副本，不替换原应用。使用自定义证书时，同样提供 `CODE_SIGN_IDENTITY`。

每轮实机验收先核对进程与本轮构建，安装位置不是 `dist` 时显式传入路径：

```bash
./scripts/verify-running.sh 1.5.0 "$HOME/Applications/ClipboardBoard.app"
```

脚本会比较运行路径、版本、构建编号、可执行文件哈希和签名，并与本轮 `dist` 构建对照；同版本旧构建也会被拒绝。

Swift 6.4 的默认测试引擎曾漏掉本项目的核心测试套件，因此测试脚本显式采用 native runner，并补充 CLT 的宏插件路径。自动化测试不等于跨应用验收；逐项证据、限制及待验收项见 [验收记录](docs/ACCEPTANCE.md)。
