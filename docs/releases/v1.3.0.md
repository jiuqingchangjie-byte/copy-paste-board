# ClipboardBoard v1.3.0

中文 | English below

## 中文

本次更新加入完整内容预览：默认悬浮 1 秒查看全文，选取片段复制入历史，以及可缩放、置顶的原图窗口。

### 新增与改进

- **悬浮完整预览**：在条目旁显示完整文本，保留换行，可滚动至全文末尾。在“完整预览选项”中可关闭悬浮，或将延时设置为 0.2–5 秒；默认 1 秒，重启后保留。
- **选取片段复制**：在预览中选择文字，按 ⌘C、点击按钮或使用右键菜单复制。仅明确复制时改写系统剪贴板并加入历史，遵守去重、当前条数上限和单条 8 MiB 限制；暂停自动记录时，显式复制仍入历史。
- **原图查看与置顶**：图片右击“查看原图”，支持原始大小、适合窗口、缩放按钮及系统双指缩放；“置顶固定”分离图片窗口，关闭历史后仍可见。提供标题栏及顶部提示区域拖动手柄；取消置顶恢复普通窗口层级。置顶窗口仅限本次运行，不是收藏功能。
- **键盘与焦点保护**：列表焦点下空格打开预览，搜索框空格仍输入文字。预览期间回车不触发历史粘贴，Esc 返回原条目和焦点，新增复制导致重排时仍按条目 ID 恢复选择。
- 按历史列表、预览内容、窗口生命周期、复制服务、设置与共用窗口部件拆分模块，兼容旧配置。

### 验证与限制

- **93 项 Swift 测试、8 项构建/安装流程测试通过**；Release 构建及严格签名检查通过。
- 本机验证了全文滚动、Unicode 片段复制入历史、原选择恢复、搜索空格、图片缩放与置顶、延时配置保存、同路径更新保留历史和原设置。
- 实体触摸板双指辅助点按/缩放、实体鼠标拖动、多显示器/全屏及其他系统版本仍待实测。CUA 拖动调用未得到可核实的坐标变化，不标为通过。详细证据见 [完整预览验收](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.3.0/docs/PREVIEW.md)。

## English

### Highlights

- **Full hover previews:** display complete text beside an entry, preserving line breaks and supporting scrolling. Configure the delay from 0.2 to 5 seconds (default: 1 second), or disable hover previews. Preferences persist across restarts.
- **Copy selected text:** use Command-C, the copy button, or the context menu to copy a selection into clipboard history. Only explicit copying writes the clipboard; deduplication, the configured history limit, and the 8 MiB item limit still apply. Explicit copying also works while automatic recording is paused.
- **Original-image viewer:** right-click an image to view it, fit it to the window, inspect its original size, or zoom. Pin the viewer above other windows independently of history. The title bar and header provide drag handles. Pinned windows are session-only viewers, not persistent favorites.
- **Keyboard isolation:** Space previews an entry when the list has focus, while search spaces remain text input. Return in a preview does not paste history. Escape restores the original entry and focus, including after new copies reorder the list.
- Separate history, preview content, window lifecycle, copying, preferences, and shared window controls into focused modules; retain legacy settings compatibility.

### Validation and remaining checks

**93 Swift tests and 8 build/install workflow tests passed**, together with Release compilation and strict signature verification. Local checks covered full-text scrolling, Unicode selection copying, restored selection, search spaces, image zoom and pinning, persisted preferences, and updates preserving user data and settings.

Physical trackpad secondary-click/zoom gestures, physical mouse dragging, multi-display/full-screen behavior, and other macOS versions still require device validation. CUA drag calls did not produce a verifiable coordinate change and are not recorded as passed. See the [acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.3.0/docs/PREVIEW.md).
