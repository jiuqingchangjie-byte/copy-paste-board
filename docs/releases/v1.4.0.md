# ClipboardBoard v1.4.0

## 中文

### 自定义全局快捷键

通过 **… → 自定义快捷键** 主动录制组合，再点击“保存”。默认仍为 **⌥V**，可通过“恢复默认 ⌥V”选择默认组合并保存。

- 支持常见字母、数字、符号、方向键、F1–F12 和部分小键盘键；至少包含 ⌘、⌥、⌃ 中一个修饰键。按物理键位绑定，显示采用美式键盘标识。
- 录制时 Esc 取消，普通字符或仅 Shift 的组合不保存，⌘Q 不会意外退出。设置窗口关闭或取消时保留原配置。
- 检查系统快捷键、常用保留组合和其他程序的排他注册。先注册候选、再保存配置，全部成功后才注销旧组合；冲突或保存失败保留原快捷键。
- 重启后恢复配置，菜单、菜单栏提示和空历史提示同步显示当前组合。长按重复按下事件只响应一次。
- 按设置模型、录制控件、冲突策略、Carbon 注册及切换事务划分模块。

### 验证与限制

**117 项 Swift 测试、8 项构建/安装流程测试通过。** 已在本机验证录制、保存、重启注册、恢复默认、另一进程占用组合导致注册失败，以及设置文件无法写入时保留旧注册和旧配置。正式安装前后历史文件一致，原设置与授权保留；运行版本、构建编号、启动哈希和签名均核对通过。

**仍待实测：实体键盘跨应用呼出、其他键盘布局、其他 macOS 版本及全屏/多桌面。** CUA 未取得可靠实体触发证据；Carbon 注册和事件处理器测试不等同硬件验收。系统接口无法枚举所有应用内部快捷键、非排他监听或后续变化，不能保证检测所有冲突。详见 [快捷键验收记录](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.4.0/docs/CUSTOM_SHORTCUT.md)。

## English

### Custom global shortcuts

Use **… → 自定义快捷键** to explicitly record a combination and save it. The default remains **Option-V**; choose “恢复默认 ⌥V” and save to restore it.

- Supports common letter, number, symbol, arrow, F1–F12, and selected keypad keys with at least Command, Option, or Control. Bindings use physical key positions with US-layout labels.
- Escape cancels recording; plain keys and Shift-only combinations are rejected. Command-Q does not quit while recording. Cancel or close leaves the existing configuration unchanged.
- Check system shortcuts, reserved app commands, and exclusive registrations. Reserve the candidate and persist settings before releasing the old shortcut. Conflicts and save failures retain the old registration and settings.
- Restore the saved shortcut at launch and update menu labels and history hints. Repeated presses while held trigger only once.
- Separate settings, recording, conflict policy, Carbon registration, and transactional switching into focused modules.

### Validation and limits

**117 Swift tests and 8 build/install workflow tests passed.** Local checks covered recording, persistence, restart registration, default restoration, actual cross-process exclusive-registration conflicts, and preservation of the old shortcut after a real settings-write failure. Existing history, settings, and permissions survived installation. Running build identity and signature checks passed.

**Physical keyboard activation across apps, other layouts/macOS versions, and full-screen/Spaces behavior remain unverified.** CUA did not produce reliable physical-trigger evidence; registration and handler tests do not substitute for hardware validation. App-local shortcuts, nonexclusive listeners, and later changes cannot all be enumerated. See the [acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.4.0/docs/CUSTOM_SHORTCUT.md).

### Download and update

[Download the compiled Apple Silicon app](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.4.0/ClipboardBoard-v1.4.0-macos-arm64.zip) and its companion `.zip.sha256` file. Source archives and `SHA256SUMS.txt` are available for developers.

Minimum deployment target: macOS 13. The app uses the existing stable self-signed certificate and **is not notarized by Apple**. No source build or Apple Developer membership is required. Quit the old app, replace it at the same location, and preserve the adjacent `ClipboardBoardData` folder. Bilingual installation instructions are included.
