# ClipboardBoard v1.6.0

中文 · English · 日本語 · 한국어

## 中文

### 四种界面语言

支持 **中文（统一简体）、English、日本語、한국어**。在历史窗口右上角 **… → 语言 / Language**，或右击菜单栏图标选择语言，保存成功后立即生效，重启后保留。

- 覆盖历史、收藏、完整预览、JSON 格式化、快捷键、存储、恢复、错误提示、相对时间和应用内无障碍标签，共 302 条文案；收藏和窗口置顶使用不同术语。
- 旧版升级继续使用中文。全新安装按系统首选语言选择；所有中文语言标识统一使用简体中文，不支持的语言回退到英语。
- 复制内容、用户自建文件夹名称保持原文，语言设置随自定义存储迁移保留。
- 四种语言的历史窗口均保持 **340 × 490 点**。顶部收藏、清空采用紧凑图标，保留完整悬浮说明和无障碍名称；长提示换行显示。

### 验证

**实际执行 136 项 Swift 测试、8 项构建／安装流程测试通过。** 四语文案完整性和参数检查通过；已在本机逐个切换四种语言，确认窗口尺寸一致、重启保留选择，原历史、收藏及现有授权保留。安装包复用验收构建 `2867C4E5`。

系统自身的权限弹窗及其他应用名称可能沿用 macOS 系统语言。其他 macOS 版本、实体日语／韩语键盘及屏幕阅读器朗读尚未逐项验收；既有多屏、全屏等待验收项继续保留。详见 [语言、术语与验收记录](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.6.0/docs/LANGUAGES.md)。

## English

### Four interface languages

Choose **中文 (Simplified Chinese), English, 日本語, or 한국어** in **… → Language** in the history window, or by right-clicking the menu bar icon. Changes apply immediately after saving and persist across restarts.

- Localize 302 app-owned strings across history, favorites, previews, JSON formatting, shortcuts, storage, recovery, errors, relative times, and accessibility labels. Favorites and keeping a window on top use distinct terms.
- Existing installations retain Chinese. New installations select a supported system-preferred language; all Chinese locale variants map to Simplified Chinese, with English as the unsupported-language fallback.
- Copied content and custom folder names remain unchanged. Language settings survive storage relocation.
- Keep the history panel at **340 × 490 points in every language**, with compact action icons, full tooltips and accessibility names, and wrapping hints.

### Validation

**136 Swift tests and 8 build/install workflow tests passed.** Catalog coverage and placeholders were checked. Live testing confirmed all four languages, identical panel dimensions, persisted language selection after restart, and preservation of existing history, favorites, and permissions. The app archive uses the accepted build `2867C4E5`.

System permission dialogs and other app names may follow the macOS language. Other macOS versions, physical Japanese/Korean keyboards, and screen-reader speech have not all been tested. Existing multi-display and full-screen acceptance items remain outstanding. See the [language and acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.6.0/docs/LANGUAGES.md).

## 日本語

日本語のインターフェイスに対応しました。履歴ウインドウの **… → 言語 / Language → 日本語** から選択できます。変更はすぐに適用され、再起動後も保持されます。履歴ウインドウはどの言語でも **340 × 490 ポイント**です。コピーした内容や自分で作成したフォルダ名は変更されません。

[Apple Silicon 版をダウンロード](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.6.0/ClipboardBoard-v1.6.0-macos-arm64.zip)。更新前にアプリを終了し、同じ場所に置き換えてください。データフォルダと保存場所の設定は保持してください。このアプリは自己署名されており、Apple の公証は受けていません。
