# ClipboardBoard v1.6.1

## 中文

本次补丁修复微信中回车、双击无法直接粘贴的兼容性问题。

- 系统“粘贴”菜单禁用时，旧逻辑会直接退出。现在会在模拟按键权限有效、原应用仍在前台、按键已松开且剪贴板未变化时，尝试一次 ⌘V。
- 菜单已执行或执行结果不确定时不补发，避免重复粘贴。
- 粘贴诊断显示具体失败阶段，并保留实际请求目标，避免面板重新打开后显示错误的目标程序。

验证：140 项 Swift 测试、8 项构建/安装流程测试通过；用户在修复构建中实机确认微信的回车、双击均已恢复。正式 1.6.1 已通过运行身份和安装包签名检查。其他应用、图片/文件、多窗口场景未在本轮逐项实测。详见[验收记录](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.6.1/docs/PASTE_COMPATIBILITY.md)。

[下载 Apple Silicon / M 系列应用包](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.6.1/ClipboardBoard-v1.6.1-macos-arm64.zip)，附同名 `.zip.sha256` 校验文件。源码 ZIP 和 `SHA256SUMS.txt` 供开发者使用。

更新前退出 ClipboardBoard，将应用替换到原路径，保留 `ClipboardBoardData` 和 `ClipboardBoardConfig` 目录。应用使用固定自签名证书，未经 Apple 公证；沿用同一路径和签名更新，无需主动重置权限。最低 macOS 13，应用包为 arm64。

## English

This patch fixes a paste compatibility issue where Return and double-click could fail in WeChat.

- A disabled native Paste menu previously stopped delivery. The app now attempts one Command-V fallback while event-posting permission, the original foreground application, released keys, and clipboard contents remain valid.
- Successful or uncertain menu actions never trigger an additional paste, preserving duplicate-paste protection.
- Paste diagnostics identify the failure stage and retain the actual request target even if the history panel reopens.

Validation: 140 Swift tests and 8 build/install workflow tests passed. The user confirmed that both Return and double-click worked again in WeChat with the fix build. The final 1.6.1 build passed running-identity and archive-signature checks. Other applications, image/file pasting, and multiple-window scenarios were not individually retested in this round. See the [acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.6.1/docs/PASTE_COMPATIBILITY.md).

[Download the Apple Silicon app](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.6.1/ClipboardBoard-v1.6.1-macos-arm64.zip) and its companion `.zip.sha256` checksum. The source archive and `SHA256SUMS.txt` are for developers.

Quit ClipboardBoard before replacing the app at its original location. Preserve the `ClipboardBoardData` and `ClipboardBoardConfig` folders. The app uses a stable self-signed certificate and is not notarized by Apple. Updating at the same path with the same identity does not require proactively resetting permissions. Requires macOS 13 or later; the app archive is arm64.
