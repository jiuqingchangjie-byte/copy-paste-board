# 收藏库与可配置存储

版本：1.5.0。日期：2026-09-12。

## 产品方案与已确认边界

采用两个职责明确的入口：**普通历史用于快速找回最近复制，收藏库用于长期整理常用内容**。

- 普通历史默认 10 条，可配置 1–50 条，继续按复制顺序淘汰。
- 收藏独立保存，不占普通历史额度，没有 50 条或其他人为条数上限；实际容量取决于磁盘。仍保留单条 8 MiB 规则。
- 收藏保存内容快照，普通历史删除、清空或淘汰不会删除收藏。取消收藏也不删除普通历史或改变系统剪贴板。
- 图片和文本内容直接保存；Finder 文件收藏保存文件 URL 引用，不复制文件本体。源文件移动或删除后，文件复制可能不可用。

### 入口与日常操作

1. 历史面板顶部“收藏”按钮、菜单栏菜单“打开收藏库”均可直达收藏库。
2. 每条历史的星标用于快速收藏到“未分类”，再次点击取消收藏；右键菜单提供相同动作。
3. 独立收藏库采用左侧目录、右侧内容列表。固定入口为“全部收藏”和“未分类”，用户可创建、重命名和删除一级文件夹。
4. 删除文件夹把其中的收藏移回“未分类”，不级联删除内容。同名及保留名称会提示。
5. 搜索作用于当前目录的内容和来源；每页 100 条，显示总数与当前范围。列表只读取元信息及有界缩略图，查看或复制时才加载原内容。
6. 支持 Command / Shift 多选当前页，批量移动、取消收藏。只选一条时可查看完整内容或复制；双击用于预览，不自动粘贴。
7. 目录管理中可清空当前目录；顶部可清空整个收藏库。清空范围不受搜索条件限制，确认框会明确范围；保留目录结构，普通历史不受影响。库内取消收藏及清空暂不支持撤销。批量操作在后台执行，保存期间禁用重复操作；全库清空后尝试回收数据库空闲空间。
8. 收藏预览继续支持 JSON 格式化、原文切换、图片缩放与置顶。只有明确复制操作写剪贴板，并沿用普通历史的去重与容量校验。

## 存储位置与迁移

通过 **… → 存储位置 → 更改存储位置** 选择目录。应用在所选目录下创建 `ClipboardBoardData`，迁移历史、收藏、设置及已有恢复副本；确认后后台复制并校验，完成才切换。

默认布局：

```text
安装目录/
├── ClipboardBoard.app
├── ClipboardBoardData/
│   ├── history.json
│   ├── settings.json
│   └── favorites.sqlite
└── ClipboardBoardConfig/
    └── storage-location.json    # 自定义位置后创建
```

自定义后，`ClipboardBoardConfig` 仍位于应用旁，记录实际数据目录。应用更新时保留该文件夹和数据目录；移动应用本身时也要带上配置文件夹。位置记录不写入签名应用包。

迁移规则：

- 不覆盖或合并已有非空目标目录，不允许放入 `.app` 内或与原数据目录相互嵌套。
- 先完成排队的历史保存、关闭收藏数据库，再复制到目标旁的临时目录。
- 校验 JSON、收藏库完整性及复制文件摘要，刷新文件，再切换存储位置记录。
- 旧目录保留副本；切换后只使用新目录，不自动合并旧副本。副本可能含已删除的旧内容，应按个人需要妥善管理。
- 迁移期间新复制暂存在内存，完成后写入最终目录；此时收藏修改和设置保存暂不可用。
- 失败时继续使用原位置；位置记录写入失败时新副本可能保留，但不会变为当前位置。
- 自定义位置缺失、磁盘未挂载或关键数据文件缺失时明确报错，不自动回落到空目录。恢复原目录连接后可通过“数据与恢复”重试。
- 建议稳定可写的本地目录。外置盘/网络目录须可访问；云盘目录可能被其客户端同步。应用本身不主动联网，数据未额外加密，目录/文件使用私有权限。

## 重启与故障恢复

历史和设置采用“临时文件 → 刷新磁盘 → 原子替换”。收藏使用系统 SQLite，事务写入、EXTRA 同步和 macOS fullfsync；每次操作提交后才报告成功。正常退出会等待保存队列完成，并保存迁移期间收集到的尾部历史。

已成功写盘的内容可在应用重启或电脑重启后加载。测试覆盖强制终止进程后恢复已提交的 70 条收藏和历史，以及未提交批量删除的回滚。**未实施整机断电或物理磁盘故障测试；尚未被轮询采集或尚未完成落盘的最后一次复制不能保证恢复。** 不把“正常退出后恢复”或进程强杀测试等同于所有硬件故障通过。

## 模块分工

| 模块 | 职责 |
| --- | --- |
| `ClipboardCore/Favorites/FavoritesRepository.swift` | 收藏去重、分页、目录、多选事务与持久化 |
| `ClipboardCore/Favorites/FavoriteModels.swift` | 目录、范围、列表元信息与分页结果 |
| `ClipboardCore/Storage/SQLiteDatabase.swift` | 绑定参数、数据库连接、事务及错误处理 |
| `ClipboardCore/Storage/DurableFile.swift` | 历史、设置和位置记录的耐久原子写入 |
| `ClipboardCore/Storage/StorageLocation.swift` | 独立位置记录、启动解析及缺失保护 |
| `ClipboardCore/Storage/StorageRelocator.swift` | 复制、完整性/摘要校验、最终位置提交 |
| `ClipboardBoard/Favorites/FavoritesLibraryView.swift` | 独立收藏库布局与列表按键 |
| `ClipboardBoard/Favorites/FavoritesLibraryController.swift` | 目录导航、分页、选择和操作确认 |
| `ClipboardBoard/Favorites/FavoritesCoordinator.swift` | 历史星标、收藏库与应用之间的接线 |
| `ClipboardBoard/Favorites/FavoriteThumbnail.swift` | 有界列表缩略图，原图不变 |
| `ClipboardBoard/Storage/StoragePreferencesController.swift` | 目录选择、迁移确认、进度与错误提示 |

SQL 不拼接用户输入，批量操作采用事务；列表不一次加载全部图片。后续若扩展多级目录或更多检索能力，可在目录模型与查询层扩展，不将数据库操作堆入窗口代码。
