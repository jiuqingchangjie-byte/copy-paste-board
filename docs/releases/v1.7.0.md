# ClipboardBoard v1.7.0

## 中文

新增应用内更新：菜单中可“检查更新”、开关“自动检查更新”，并自行选择“自动下载并安装更新”。默认自动检查，默认不自动安装。

- 使用 Sparkle 2，更新包和更新清单都验证 EdDSA 签名；下载内容校验成功后才解包。
- 更新替换应用本体，保留旁边的历史、收藏与存储位置配置；存储迁移未完成时不会退出应用进行安装。
- 更新偏好保存在 Sparkle 管理的本机设置中，重启不覆盖用户选择。
- 更新会连接 GitHub 获取清单和安装包，不上传剪贴板内容，关闭系统分析数据收集。

验证：146 项 Swift 测试、17 项脚本测试通过。使用独立本地更新源实测手动升级、后台下载后退出安装、重启、更新设置保留和签名篡改拒绝；测试历史、收藏、自定义存储配置及两项粘贴权限保留。

1.6.1 及更早版本需要手动安装本版本一次，之后才支持应用内升级。适用于 Apple Silicon、macOS 13+。应用继续使用固定自签名证书，未经 Apple 公证。详见 [自动更新说明](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.7.0/docs/AUTO_UPDATE.md)。

[下载手动安装包](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.7.0/ClipboardBoard-v1.7.0-macos-arm64.zip)。首次升级请退出旧版、替换原路径下的应用，保留应用旁的 `ClipboardBoardData`、`ClipboardBoardConfig` 和实际自定义数据目录。`update-arm64.zip` 与 `appcast.xml` 供应用内更新器使用。

## English

Adds in-app updates through Sparkle 2. Use the menu to check for updates, enable or disable automatic checks, and opt in to automatic downloading and installation. Automatic checking is enabled by default; automatic installation is opt-in.

Update archives and feeds require EdDSA signatures, and archives are validated before extraction. Updates replace the application while preserving adjacent history, favorites, and storage configuration. Storage relocation must finish before the application exits for an update. Sparkle persists update preferences without resetting them on launch.

Update checks and downloads connect to GitHub. Clipboard contents are never sent, and system profiling is disabled. Users on 1.6.1 or earlier need to install this version manually once. Requires Apple Silicon and macOS 13+. The app retains its stable self-signed identity and is not notarized by Apple. See [automatic update documentation](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.7.0/docs/AUTO_UPDATE.md).

Validation: 146 Swift tests and 17 script tests passed. Isolated local update feeds verified manual upgrading, background download and installation on quit, restart, persisted update preferences, and rejection of tampered signatures. Test history, favorites, custom storage configuration, and both paste permissions were retained.

[Download the manual installation archive](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/download/v1.7.0/ClipboardBoard-v1.7.0-macos-arm64.zip). Quit the old app, replace it at the same path, and preserve adjacent data/configuration folders and any custom data directory. The update archive and signed appcast are intended for the in-app updater.
