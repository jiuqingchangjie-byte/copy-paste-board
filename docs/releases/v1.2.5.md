# ClipboardBoard v1.2.5

中文 | English below

本次更新集中完善日常使用：历史最多 50 条、数据异常可恢复、文本编辑中的回车粘贴修复，以及安装更新时的身份连续性。

## 中文

### 新增与改进

- **历史上限统一为 1–50 条**，默认 10 条。满额后每新增一条不同内容，只淘汰最早复制的一条；重复复制去重并移到最前，使用历史粘贴不改变复制顺序。旧设置和旧历史超过 50 时，自动保留最新 50 条。
- **新增“数据与恢复”**。读写失败时保留本次记录，提供重试；损坏文件先留存原始副本，再经用户确认重建。恢复保留本次复制，并尊重已经执行的删除和清空。历史与设置增加格式版本，更新版本的数据不会被破坏性重建。
- **修复文本编辑中的回车粘贴**。补齐 AppKit 快捷键与搜索框命令处理，保护输入法组词并忽略长按重复。用户已在验收构建中确认回车正常粘贴一次，双击也可用。
- **登录自启可重新注册**。系统找不到登录项时，允许用户再次开启；不再把开关永久禁用。实际开启、关闭均已验证。
- **固定路径安装和更新**。新增安装脚本，核对签名身份、保留已有数据目录，不重置系统权限。本机同签名升级和重装均保留已有粘贴权限。
- **测试前核对实际运行构建**。版本、运行路径、构建编号、可执行文件哈希和签名必须与待测构建一致，同版本旧进程也会被识别。
- 新增项目待办、数据恢复体验说明、安装发布说明和逐项验收记录；同步更新中英文 README。

### 验证结果

- **81 项 Swift 测试、8 项构建与安装流程测试通过**，Release 编译和严格签名校验通过。
- 本机验证了设置边界、损坏数据恢复、登录项重新注册及开关、同签名更新保留授权。
- 用户确认文本编辑中 **Option+V、回车单次粘贴、双击粘贴**可用。
- 其他软件中的图片/文件接收、全屏与多桌面、完整输入法场景、注销重登和另一台 Mac 的安装仍待验收。详见 [验收记录](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.2.5/docs/ACCEPTANCE.md)。

### 下载与安装

**这是源码发行版，不包含已公证的通用安装包。** 下载 `ClipboardBoard-v1.2.5-source.zip` 或 GitHub 自动生成的 Source code 压缩包，按 [中文 README](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.2.5/README.md) 构建安装。`SHA256SUMS.txt` 用于校验独立源码 ZIP。

- 运行要求：macOS 13+；构建要求：Swift 5.9+ 和 Xcode / Command Line Tools；测试要求：macOS 14+、Swift 6+、Python 3。
- 目前已在 Apple Silicon 上验证，构建脚本生成本机架构，Intel 仍需单独验证。
- 本机开发签名与正式分发签名不同。尚未配置 Developer ID 和公证凭据，因此本次不附未经公证的开发应用包。
- 正常更新应保持固定签名身份和安装位置。首次授权仍由 macOS 控制；撤销权限、系统重置或更换签名身份可能需要重新允许。
- 历史及设置仍保存在应用旁的 `ClipboardBoardData`。移动应用时一并移动该目录；更新前退出旧进程。

完整变更见 [CHANGELOG](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.2.5/CHANGELOG.md)，后续开发见 [TODO](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.2.5/TODO.md)。

## English

### Highlights

- **A consistent 1–50 entry limit**, with 10 by default. Each new distinct copy evicts only the oldest entry when full. Duplicate copies move to the front without increasing the count; pasting from history does not reorder it. Legacy limits and histories above 50 are normalized to the newest 50 entries.
- **Data recovery controls** preserve session entries after read/write failures, offer retry, and archive damaged originals before user-confirmed rebuilding. Recovery respects session deletions and clearing. History and settings now carry format versions; newer formats are protected from rebuilding.
- **Return-to-paste fix in TextEdit**, covering AppKit key-equivalent and search-field command paths while protecting IME composition and ignoring key repeats. The user confirmed a single successful Return paste and working double-click paste in the accepted build.
- **Retry missing login registrations** instead of permanently disabling the switch. Registration and disabling were verified on the local Mac.
- **Stable-path installation and updates** validate signing identity and preserve destination data without resetting privacy permissions. Existing permissions survived local same-identity upgrades and reinstalls.
- **Preflight checks for live testing** compare the running path, version, build ID, executable hash, and signature against the intended build, including older builds with the same version number.
- Add a development backlog, recovery design, installation/release guidance, and evidence-based acceptance records; update both READMEs.

### Validation

**81 Swift tests and 8 build/install workflow tests passed**, together with the Release build and strict signing checks. Live checks covered settings boundaries, damaged-data recovery, login registration, and permission continuity. The user confirmed Option+V, single Return paste, and double-click paste in TextEdit.

Cross-application image/file delivery, full-screen and Spaces behavior, complete IME scenarios, logout/login, and installation on another Mac remain outstanding. See the [acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.2.5/docs/ACCEPTANCE.md).

### Downloads and compatibility

**This is a source release; it does not include a notarized app installer.** Download `ClipboardBoard-v1.2.5-source.zip` or GitHub's Source code archives and follow the [English README](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.2.5/README.en.md). `SHA256SUMS.txt` covers the standalone source ZIP.

The app targets macOS 13+ and Swift 5.9+ builds; tests require macOS 14+, Swift 6+, and Python 3. Apple Silicon was verified; builds target the host architecture and Intel remains unverified. Developer ID and notarization credentials are not configured, so no unnotarized development app is attached.

Keep the signing identity and installation path stable for updates. Initial consent remains under macOS control, and permission revocation, system resets, or identity changes may require it again. Data remains in `ClipboardBoardData` beside the app; move that directory together with the app and quit the old process before updating.
