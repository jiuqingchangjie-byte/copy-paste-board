## 使用约定

- 鼠标停留在同一条目上默认 1 秒，在条目旁显示预览；自动选择屏幕内可用位置。可移入预览窗口滚动、选择文字。离开条目会取消尚未触发的计时；已经显示的预览保留，方便移入操作。停留到另一条目会替换内容。
- **… → 完整预览选项**：可关闭悬浮预览，或设置 0.2–5 秒等待时间，支持小数。关闭悬浮后仍可使用右键和列表空格。旧设置自动采用启用、1 秒；保存失败保留原设置。
- 文本保留全部换行、Unicode 与原始内容，长行按窗口宽度折行，竖向滚动。选择文字后按 **⌘C**、点击“复制选中文本”，或通过文字右键菜单复制。
- **仅明确复制选中文本时**才改写系统剪贴板并加入历史，来源为“剪贴板预览”；继续遵守去重、当前条数上限与单条 8 MiB 限制。显式复制在“暂停自动记录”时仍加入历史；查看、选择文字、滚动、缩放与关闭均不写剪贴板。
- 图片右击选择“查看原图”。macOS 已启用触摸板“双指点按或轻点”辅助点按时，该系统手势进入相同右键菜单，不拦截普通双指滚动。
- 原图窗口初次打开适合窗口；支持 **− / +**、**原始大小（100%）**、**适合窗口**和系统双指缩放。100% 以原图像素尺寸作为窗口点坐标显示，使用原始图片数据，不拿缩略图放大。高分辨率屏幕的点与物理像素存在比例差异。
- 点击“置顶固定”将图片从历史窗口分离，关闭历史或切换应用后仍保持浮动显示。可拖动系统标题栏或窗口顶部提示区域移动；“取消置顶”恢复普通窗口层级，关闭按钮 / Esc 关闭查看器。
- 置顶图片为本次运行的独立窗口快照，不增加历史条数、不修改磁盘图片，不等同于收藏功能。删除/清空历史不会自动关闭已分离的图片；需关闭查看器。退出应用后不恢复置顶窗口。
- 历史列表获得焦点时，空格打开预览；搜索框中的空格、修饰键组合及输入法组词不触发预览。预览打开期间，回车不会调用历史粘贴。
- Esc 关闭预览后，按条目 ID 恢复打开前的选择及搜索/列表焦点。期间新增复制导致列表重排时仍找回同一条目；原条目已删除或被淘汰则保留列表当前有效选择。再次 Esc 关闭历史。

## 模块与扩展位置

| 目录 / 文件 | 职责 |
| --- | --- |
| `Sources/ClipboardBoard/History/HistoryPanelController.swift` | 历史列表、搜索、预览入口接线、原选择恢复；不渲染预览内容 |
| `History/KeyboardPanel.swift` | 历史按键路由，保护搜索输入和 IME，隔离预览期间的粘贴 |
| `History/HistoryTableView.swift` | 鼠标跟踪、离开/滚动取消、按实际右击条目创建菜单 |
| `History/HistoryEntryViews.swift`、`HistoryPanelAppearance.swift` | 历史卡片和面板外观 |
| `Preview/HoverPreviewScheduler.swift` | 单条目延时与失效取消，避免旧条目延迟弹出 |
| `Preview/HistoryPreviewCoordinator.swift` | 临时预览与分离图片的所有权、关闭、置顶、来源删除处理；不接触粘贴服务或剪贴板 |
| `Preview/EntryPreviewWindowController.swift` | 窗口装配、屏幕定位、置顶层级、拖动入口 |
| `Preview/PreviewPanel.swift` | 预览窗口自身的 Esc 路由，不注册历史接受动作 |
| `Preview/TextPreviewViewController.swift` | 全文滚动与选区，复制只发出显式回调 |
| `Preview/ImagePreviewViewController.swift` | 原图解码、滚动、缩放、最终布局后的首次适配 |
| `Preview/PreviewCopyService.swift` | 唯一预览写入路径；写入后显式入历史，抑制监视器重复采集 |
| `Preferences/PreviewPreferencesController.swift` | 预览选项编辑、校验与保存失败提示 |
| `Sources/ClipboardCore/PreviewSettings.swift` | 设置默认值、数值边界与 Codable 兼容 |
| `WindowChrome/DraggableHeaderView.swift` | 历史窗口与预览共用的拖动手柄，保留内部按钮点击 |

新增内容类型时，从 `EntryPreviewWindowController` 的内容控制器选择扩展；窗口与剪贴板逻辑不放进内容视图。新增复制形式时通过 `PreviewCopyService` 接入，不调用历史粘贴服务。

## 测试版本前置核对

每轮实机测试前必须执行并保存输出；重编译或重启后重新核对：

```bash
# 固定安装路径
./scripts/verify-running.sh 1.3.0 "$HOME/Applications/ClipboardBoard.app"

# 本轮隔离测试副本（参考构建默认仍是 dist/ClipboardBoard.app）
./scripts/verify-running.sh 1.3.0 "$PWD/.build/acceptance-1.3.0/live/ClipboardBoard.app"
```

核对运行路径、版本、构建编号、进程启动时二进制 SHA-256 与固定签名；只检查磁盘版本不算通过。任何不匹配都先停止测试，再退出旧进程并启动目标构建。

源码自动化通过 `scripts/test.sh` 先编译当前源码再运行测试，不把已安装旧应用作为测试目标。
