# ClipboardBoard v1.5.0

中文 | English below

## 中文

### 独立收藏库

- 历史条目新增星标快捷收藏，顶部“收藏”及菜单栏均可直达独立收藏库。
- 收藏不占普通历史额度，没有 50 条或其他人为条数上限；普通历史仍为默认 10 条、可配置 1–50 条。单条 8 MiB 规则保留。
- 提供全部收藏、未分类与自建一级文件夹，支持重命名、多选移动／取消收藏、清空目录或整个收藏库。删除目录会把内容移回未分类，不删除内容；清空前明确确认范围。
- 收藏列表分页加载元信息和有界缩略图，完整内容按需读取。支持搜索、完整预览、JSON 格式化和显式复制；双击预览不自动粘贴。
- 普通历史的删除、清空与淘汰不影响收藏。收藏文件仍是文件 URL 引用，不复制文件本体。

### 可配置存储与恢复

通过 **… → 存储位置** 选择目录，一起迁移历史、收藏、设置和已有恢复副本。后台复制与校验成功后才切换，旧目录保留；不覆盖非空目标，不把不可用自定义位置自动当作空库。

历史和设置刷新后原子替换；收藏采用 SQLite 事务与完整同步。批量收藏操作在后台执行，正常退出等待保存完成。自定义位置记录在应用旁的 `ClipboardBoardConfig/storage-location.json`，更新或移动应用时保留此配置文件夹和实际数据目录。

### 验证与边界

**127 项 Swift 测试、8 项构建/安装流程测试通过。** 已实测星标收藏、目录创建、多选移动/取消、全库清空、图片缩略图、实际目录迁移和 Command-C 复制。迁移后强制终止测试应用，再启动可恢复新位置的历史、收藏及新目录，未导回旧副本。正式安装保留原历史、设置与授权，并核对运行构建、哈希及签名。

恢复保证针对**已成功落盘的数据**；尚未采集或未完成保存的最后一次复制不能保证恢复。未进行整机断电或物理磁盘故障测试。收藏取消及清空暂无撤销；选择云盘/网络目录时外部软件可能同步文件，应用不主动联网，数据未额外加密。旧版本遗留的实体键盘、多屏/全屏等待验收项不因本次测试标记为通过。详见 [产品设计与验收记录](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.5.0/docs/FAVORITES_AND_STORAGE.md)。

## English

### Independent favorites

- Save history entries with a star and open a separate library from the history header or menu bar.
- Favorites do not consume history capacity and have no artificial item-count limit. Ordinary history remains configurable from 1 to 50 entries, with 10 by default. The 8 MiB per-item limit still applies.
- Browse All Favorites, Unfiled, and user-created folders. Rename folders, move/remove multiple selections, or clear a folder/library with explicit scope confirmation. Deleting a folder moves its contents to Unfiled instead of deleting them.
- Page through lightweight metadata and thumbnails; load full content on demand. Search, preview, format JSON, and explicitly copy. Double-click previews rather than automatically pasting.
- Clearing or evicting ordinary history never deletes favorites. File favorites retain URL references, not copies of the original files.

### Configurable storage and recovery

Use **… → 存储位置** to relocate history, favorites, settings, and existing recovery copies. Copy and verify in the background before switching, retain the original directory, reject nonempty targets, and report unavailable custom locations rather than creating an empty fallback.

JSON files are flushed before atomic replacement; favorites use SQLite transactions and full synchronization. Bulk operations run in the background and normal exit waits for saves. Custom storage is recorded in `ClipboardBoardConfig/storage-location.json` beside the app. Preserve this configuration folder and the actual data directory during updates or moves.

### Validation and limits

**127 Swift tests and 8 build/install workflow tests passed.** Live checks covered stars, folders, bulk move/removal, clearing, image thumbnails, actual relocation, and Command-C copying. Force-terminating the relocated test app and restarting restored its new history, favorites, and folder without merging the old copy. Installation preserved existing history, settings, and permissions; running build identity and signature checks passed.

Recovery applies to **successfully committed data**. Copies not yet captured or flushed cannot be guaranteed after a failure. No full-machine power-cut or physical disk-failure test was performed. Favorite deletion/clearing has no undo. External cloud/network software may sync selected folders; the app does not initiate networking or add encryption. Previously outstanding hardware-keyboard, display, and Spaces checks remain outstanding. See the [design and acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.5.0/docs/FAVORITES_AND_STORAGE.md).
