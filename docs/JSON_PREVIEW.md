# 完整预览内一键 JSON 格式化

版本：1.3.1。日期：2026-09-12。

## 使用

1. 复制 JSON 到系统剪贴板，打开历史记录。
2. 右击条目选择“预览完整内容”（也可悬浮预览或列表焦点下按空格）。
3. 点击顶部 **JSON 格式化**，以两空格缩进和换行显示完整 JSON。
4. 点击 **查看原文**恢复复制时的原文，包括原有空白和换行。格式化后的文字也可滚动、选择部分内容复制。

格式化只改变当前预览，**不粘贴、不写系统剪贴板、不覆盖历史记录**。只有用户明确执行复制时才写入选中内容并加入历史。无效 JSON 在底部显示行、列和错误原因，保留原文与原选区；不会猜测修复尾逗号、单引号或注释。

## 实现拆分

| 文件 | 职责 |
| --- | --- |
| `Sources/ClipboardCore/Formatting/JSONTextFormatter.swift` | 校验 JSON 语法并调整字符串外的空白；不经过浮点数/字典解码 |
| `Sources/ClipboardBoard/Preview/JSONPreviewFormattingController.swift` | 格式化/原文按钮状态、后台执行、结果缓存、忽略已取消请求的结果 |
| `Sources/ClipboardBoard/Preview/TextPreviewViewController.swift` | 组装工具栏、全文与状态提示，切换当前显示内容 |
| `Sources/ClipboardBoard/Preview/PreviewTextView.swift` | 只读选区和显式复制；沿用已有历史复制服务 |

保留数字词法表示（包括超长整数、小数、负零、指数）、字符串转义、键顺序和重复键，仅更改缩进和换行。对象、数组和合法的顶层字符串/数字/布尔值/null 均可处理；文件路径预览和图片预览不显示 JSON 按钮。

格式化在独立串行队列执行。正在处理时禁用重复格式化；“查看原文”使未完成的结果失效，旧结果不会覆盖用户刚恢复的原文。关闭预览不会被后台回调重新打开。

限制：输入最多 8 MiB、嵌套最多 128 层、格式化结果最多 32 MiB，超出时提示并保留原文。格式化后复制仍遵守既有单条 8 MiB 限制。采用严格 JSON 语法，不支持 JSON5、注释、尾逗号或开头 BOM。

语法依据：[RFC 8259](https://www.rfc-editor.org/info/rfc8259/)。
