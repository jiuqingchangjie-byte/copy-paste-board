# 界面语言与验收

更新：2026-09-13。版本：1.6.0。[发布说明](releases/v1.6.0.md) · [GitHub Release](https://github.com/jiuqingchangjie-byte/copy-paste-board/releases/tag/v1.6.0)。

## 使用

点击历史窗口右上角“更多选项”，或右击菜单栏图标，选择“语言 / Language”：

- 中文：统一使用简体中文，不另设地区版本。
- English
- 日本語
- 한국어

选择后先保存设置，保存成功再立即刷新应用界面；无需重启。语言菜单始终用各语言自己的名称，方便误选后切回。旧版设置缺少语言字段时保留中文；全新安装按系统首选语言选择，所有中文语言标识统一映射为简体中文，找不到支持的语言时使用英语。当前仅提供四种明确的语言选择，不额外提供持续跟随系统的选项。

设置随历史、收藏一起迁移到自定义存储位置。切换不改写复制内容、自建文件夹名称或已保存的收藏类型，不增加复制记录。历史与收藏预览在切换时关闭；收藏窗口保留目录、搜索和选择。快捷键编辑、模态对话框、收藏保存或存储迁移期间需先完成当前操作。

macOS 自身的权限窗口、文件选择器及其他应用的名称由系统控制，可能沿用系统语言。应用自己的菜单、提示、搜索按钮无障碍标签、预览、设置、错误信息和相对时间采用所选语言。

English: Open **More Options → Language**, then select your language. The change applies immediately and is remembered after restart.

日本語：**その他のオプション → 言語 / Language** から言語を選択してください。すぐに適用され、再起動後も保持されます。

한국어: **추가 옵션 → 언어 / Language**에서 언어를 선택하세요. 즉시 적용되며 다시 실행한 후에도 유지됩니다.
