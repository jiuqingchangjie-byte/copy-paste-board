## 中文

### 新增 JSON 一键格式化

复制 JSON 后打开“预览完整内容”，点击 **JSON 格式化** 即可按两空格缩进显示；点击 **查看原文** 恢复复制时的完整原文，包括原有空白和换行。

- 保留长整数、长小数、负零、指数、字符串转义、键顺序和重复键，仅调整展示空白。
- 格式化不触发粘贴、不改系统剪贴板、不覆盖历史；格式化结果可滚动和选取片段复制，只有显式复制才写入剪贴板并加入历史。
- 无效 JSON 提示错误行列及原因，原文和原选区保持；不猜测修复尾逗号、单引号或注释。
- 后台处理并防止重复点击；切回原文后旧请求不会覆盖当前内容。格式化、状态控制和复制视图按职责拆分。

### 验证与边界

**105 项 Swift 测试、8 项构建/安装流程测试通过**。已在本机验证系统剪贴板采集 → 完整预览 → 格式化、原文恢复、长数字精度、片段复制、错误提示和 Esc 返回原选择。每轮实机测试前核对运行路径、版本、构建编号、启动哈希和签名。更新后原历史、设置及授权保留。

输入最多 8 MiB、嵌套最多 128 层、格式化输出最多 32 MiB；复制仍受单条 8 MiB 限制。采用严格 JSON 语法，不支持 JSON5、注释、尾逗号或开头 BOM。实体触摸板、图片拖动、多屏/全屏等原预览待验收项未因本次 JSON 测试标记为通过。详见 [JSON 格式化验收](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.3.1/docs/JSON_PREVIEW.md)。

## English

### One-click JSON formatting

Copy JSON, open the full-content preview, and click **JSON 格式化** to display it with two-space indentation. **查看原文** restores the exact original text, including surrounding whitespace and line endings.

- Preserve number lexemes and precision, escapes, object order, and duplicate keys; change only presentation whitespace.
- Formatting never pastes or writes the clipboard/history. Formatted text remains scrollable and selectable; only explicit copying writes the selection into clipboard history.
- Invalid JSON reports the line, column, and reason while retaining the original text and selection. Trailing commas, single quotes, and comments are not silently repaired.
- Background processing prevents duplicate requests and stale results from replacing a restored original. Formatting, presentation state, and copying are separate modules.

### Validation and limits

**105 Swift tests and 8 build/install workflow tests passed.** Live checks covered clipboard capture through preview formatting, exact original restoration, large numbers, selected-text copying, error messages, and Escape selection restoration. Running build identity and signatures were verified before live testing. Existing history, settings, and permissions survived the update.

Limits: 8 MiB input, 128 nesting levels, and 32 MiB formatted output. Copying retains the existing 8 MiB item limit. Strict JSON is required; JSON5, comments, trailing commas, and a leading BOM are unsupported. Previously unverified trackpad gestures, image dragging, and multi-display/full-screen scenarios remain outstanding. See the [acceptance record](https://github.com/jiuqingchangjie-byte/copy-paste-board/blob/v1.3.1/docs/JSON_PREVIEW.md).
