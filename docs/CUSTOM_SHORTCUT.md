# 自定义快捷键：实现与验收

版本：1.4.0。日期：2026-09-12。

## 使用方式

在历史面板的 **… → 自定义快捷键** 中，点击“录制快捷键”或录制区域，按下组合键，再点“保存”。至少包含 ⌘、⌥、⌃ 中一个修饰键；支持常见字母、数字、符号、方向键、F1–F12 与部分小键盘按键。

- 录制期间，Esc 取消本次录制；回车、普通字符或仅 Shift 的组合不会保存。录制中的 ⌘Q 不会退出应用。
- “恢复默认 ⌥V”先修改候选值，点击保存后生效。取消或关闭窗口不改变当前设置。
- 保存成功后更新菜单栏提示、菜单入口和空历史提示，注销旧组合；重启后读取同一配置。
- 录制使用物理键码，显示按美式键盘位置标识，不把 Option 生成的特殊字符或输入法文本当作快捷键。切换键盘布局不改变绑定的按键位置。
- 设置窗口打开时，当前历史热键用于录制当前组合（正在录制时），不会意外弹出历史覆盖设置窗口。离开设置窗口会结束录制。

## 冲突与保存保护

先校验修饰键及常用编辑/系统组合，再通过 `CopySymbolicHotKeys` 检查已启用的系统快捷键，并尝试 Carbon 排他注册。旧组合在此期间保持注册；新组合注册和配置保存均成功后，才切换事件路由并注销旧组合。

注册冲突时不写配置；保存失败时注销新候选、保留旧注册，窗口显示错误并允许重新录制。相同组合只保存配置，不重复安装事件处理器或注册。过期注册 ID、取消的候选 ID 不触发历史；按住按键产生的重复按下事件只响应一次，释放后可再次使用。

**接口边界：**系统可枚举快捷键、应用内保留组合及其他进程的排他注册可检查；其他程序的非排他 Carbon 注册、应用内部快捷键、事件拦截和后续修改无法全面枚举。不能保证检测所有软件的全部冲突。Carbon 的非排他注册允许多进程共存，本版采用排他注册；实际系统测试仍发现既有非排他注册不能一概判为冲突。

启动时若保存的组合注册失败，保留配置并显示问题，菜单栏入口仍可用，可重新配置或恢复默认。旧配置缺少 shortcut 字段时采用 ⌥V；非法键码或修饰位归一化到默认，不丢弃其他设置。

## 模块

| 文件 | 职责 |
| --- | --- |
| `Sources/ClipboardCore/Shortcuts/KeyboardShortcut.swift` | 持久化键码/修饰键、结构校验、默认值、显示名称 |
| `Sources/ClipboardBoard/Shortcuts/ShortcutConflictPolicy.swift` | 保留组合、系统快捷键检查与 Carbon 修饰位映射 |
| `Shortcuts/CarbonHotKeyBackend.swift` | 单个事件处理器、排他注册生命周期、按下/释放事件与重复保护 |
| `Shortcuts/GlobalHotKey.swift` | 候选注册 → 保存 → 切换 → 注销旧值；失败保留旧状态 |
| `Shortcuts/ShortcutRecorderView.swift` | 主动录制与专用窗口按键路由，不安装全局键盘监听器 |
| `Sources/ClipboardBoard/Preferences/ShortcutPreferencesController.swift` | 编辑候选、恢复默认、取消、保存与错误提示 |
| `AppDelegate.swift` / `HistoryPanelController.swift` | 应用接线、重启注册、菜单入口及动态快捷键提示 |
